# Discipline DZ — منصة الانضباط الرياضي (Next.js + Prisma + Supabase)

## التشغيل محليًا
1. أنشئ مشروعًا مجانيًا في https://supabase.com ثم انسخ رابطي الاتصال (Project Settings ▸ Database).
2. `cp .env.example .env` وعبّئ DATABASE_URL وDIRECT_URL وAUTH_SECRET وADMIN_EMAIL وADMIN_PASSWORD.
3. `npm install`
4. `npx prisma db push`   (ينشئ الجداول؛ للمشاريع القديمة يُضيف عمودي source وcardId)
5. `npm run seed`         (ينشئ النادي + مستخدم المدير؛ أضف `SEED_DEMO=1` قبله للحصول على بيانات تجريبية)
6. `npm run dev` ثم افتح http://localhost:3000 وادخل بالبريد وكلمة السر التي وضعتها.

## بناء الإنتاج
`npm run build && npm start`

## النشر على Netlify (بدون أوامر على جهازك)
هذا مشروع Next.js بخادم وقاعدة بيانات، فلا يعمل بالسحب والإفلات في Netlify Drop. الطريقة:
1. أنشئ مستودعًا **خاصًا (Private)** على GitHub وارفع إليه محتوى هذا المجلد (وليس ملف `setup.sql`).
2. في Supabase ▸ SQL Editor الصق محتوى `setup.sql` (ملف منفصل، يُسلَّم مع المشروع وفيه كلمة السر المؤقتة) واضغط Run: ينشئ الجداول والنادي ومستخدم المدير.
3. في Netlify: Add new site ▸ Import an existing project ▸ GitHub ▸ اختر المستودع.
4. قبل Deploy أضف المتغيرات: DATABASE_URL وDIRECT_URL وAUTH_SECRET (انظر .env.example).
5. Deploy ثم ادخل بالبريد `admin@club.dz` وكلمة السر المؤقتة المرفقة مع الملف، وغيّرها فورًا من «حسابي». ثم عدّل اسم النادي والموسم من صفحة «الإدارة».

## الأدوار والمستخدمون
- **manager (مدير):** كل الصلاحيات + صفحة «الإدارة» (إضافة/حذف المستخدمين وتغيير أدوارهم، اسم النادي والموسم).
- **admin (مشرف):** إضافة وتعديل وحذف اللاعبين والمباريات والبطاقات والعقوبات.
- **viewer:** عرض فقط.

## قواعد الانضباط المطبّقة
- كل 4 بطاقات صفراء في الموسم = **مباراتا إيقاف**، والحمراء = مباراة إيقاف. للتغيير عدّل `YELLOW_BAN` و`RED_BAN` في `lib/data.ts`.
- **الإيقاف يُنفَّذ في المباريات الرسمية فقط (بطولة وكأس)**؛ الودية والدورات لا تُحتسب.
- عدد مباريات العقوبة يُعدَّل من صفحة العقوبات (0 = إلغاء). **حذف بطاقة أو مباراة يحذف العقوبة التلقائية الناتجة عنها**، وتبقى العقوبات اليدوية كما هي.
- العقوبة لا تُنفَّذ إلا في مباراة رسمية **لاحقة** لمباراة مصدرها (بالتاريخ ثم ترتيب الإدخال عند التعادل).
- تصدير الموقوفين: صفحة العقوبات ▸ «تصدير CSV»، والطباعة بـCtrl+P.
- الحساب يُقفل 15 دقيقة بعد 5 محاولات دخول فاشلة. الخروج وتغيير كلمة السر يُلغيان الجلسات القديمة.
- بعد أول `npm install` (شغّله مرة على جهازك) ارفع ملف `package-lock.json` إلى المستودع لتثبيت الإصدارات.
