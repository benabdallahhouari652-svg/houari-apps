# متجر تطبيقات بن عبدالله الهواري 🇩🇿

متجر إلكتروني جزائري رقمي شامل وعصري لعرض واستخدام التطبيقات والمنصات والأدوات الرياضية والتعليمية للمدربين والرياضيين وحراس المرمى.

من فكرة وتطوير المربي الرياضي ومدرب حراس المرمى **بن عبدالله الهواري**.

## المميزات الاحترافية بالمتجر

- 📱 **تطبيق ويب تقدمي (PWA):** إمكانية تثبيت المتجر مباشرة على هواتف الأندرويد والآيفون مع دعم العمل أوفلاين.
- ⭐ **نظام المفضلة (Favorites):** حفظ التطبيقات المفضلة وتصفيتها بنقرة واحدة باستخدام التخزين المحلي (`localStorage`).
- 📊 **تصنيفات تفاعلية مع عداد ديناميكي:** إظهار عدد التطبيقات المتوفرة في كل تصنيف فورياً.
- 🔎 **محرك بحث فوري متقدم:** بحث شامل بالاسم، الكلمات المفتاحية، والوصف، مع زر مسح سريع وعداد للنتائج.
- 💬 **إشعارات منبثقة (Toast Notifications):** عند إضافة تطبيقات للمفضلة أو نسخ روابط المشاركة.
- 🌗 **وضع ليلي ونهاري احترافي:** يحفظ اختيار المستخدم تلقائياً.
- 📱 **روابط مباشرة وتفاصيل كاملة:** إمكانية التجربة المباشرة أو تحميل ملفات الـ **APK** مع قائمة المميزات والوظائف لكل تطبيق.

## التشغيل محليًا

افتح `index.html` في المتصفح مباشرة، أو شغّل خادمًا محليًا:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## النشر

المستودع مناسب للنشر على **Netlify** أو **GitHub Pages** أو **Vercel** كموقع ثابت:

- **Netlify:** Add new site ← Import from Git ← اختر المستودع ← اترك أمر البناء فارغًا وأدخل `.` كمجلد للنشر.
- **GitHub Pages:** من إعدادات المستودع Settings ← Pages ← اختر الفرع `main` والمجلد `/ (root)`.
