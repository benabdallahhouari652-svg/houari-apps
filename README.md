# منصات وتطبيقات بن عبدالله الهواري 🇩🇿

منصة جزائرية تعرض التطبيقات والأدوات الرياضية والتعليمية الرقمية للمدربين والرياضيين وحراس المرمى.

من فكرة وتطوير المربي الرياضي ومدرب حراس المرمى **بن عبدالله الهواري**.

## المميزات

- عرض التطبيقات في بطاقات مع بحث فوري وتصنيفات.
- صفحة تفاصيل لكل تطبيق (الوصف، المميزات، روابط التجربة والتحميل).
- وضع ليلي ونهاري.
- تصميم متجاوب يعمل على الجوال والحاسوب.
- ملف واحد `index.html` بلا اعتماديات، ولا يحتاج إلى بناء أو تثبيت.

## إضافة تطبيق جديد

افتح `index.html` وابحث عن المصفوفة `APPS` داخل وسم `<script>`، ثم أضف عنصرًا جديدًا في آخرها (لا تنسَ الفاصلة بعد العنصر السابق):

```js
{
  id: "my-app",                       // معرّف لاتيني فريد
  name: "اسم التطبيق",
  desc: "وصف قصير يظهر في البطاقة.",
  long: "وصف مفصّل يظهر في صفحة التفاصيل (اختياري).",
  cat: ["games", "gk"],               // تصنيف أو أكثر
  tag: "ألعاب رياضية",                // نص التصنيف المعروض
  status: "new",                      // live | new | dev | soon
  url: "https://example.netlify.app/",
  features: ["ميزة 1", "ميزة 2"],
  keys: "كلمات مفتاحية للبحث",
  icon: "⚽",
  logo: "",                           // رابط صورة الشعار (اختياري)
  badge: ""                           // شارة صغيرة (اختياري)
}
```

### التصنيفات المتاحة (`cat`)

| الرمز | المعنى |
|---|---|
| `gk` | حراس المرمى |
| `football` | كرة القدم |
| `games` | الألعاب الرياضية |
| `books` | الكتب والأدلة |
| `coach` | أدوات المدربين |
| `edu` | تطبيقات تعليمية |

### حالات التطبيق (`status`)

| القيمة | تظهر كـ |
|---|---|
| `live` | متاح الآن |
| `new` | جديد |
| `dev` | قيد التطوير |
| `soon` | قريبًا |

### حقول اختيارية

`play` رابط Google Play، `apk` رابط تحميل ملف APK، `support` رابط الدعم، `video` فيديو تعريفي، `shots` مصفوفة روابط لقطات الشاشة، `urlLabel` نص زر الرابط الرئيسي.

## التشغيل محليًا

افتح `index.html` في المتصفح مباشرة، أو شغّل خادمًا محليًا:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## النشر

المستودع مناسب للنشر على **Netlify** أو **GitHub Pages** أو **Vercel** كموقع ثابت:

- **Netlify:** Add new site ← Import from Git ← اختر المستودع ← اترك أمر البناء فارغًا وأدخل `.` كمجلد للنشر.
- **GitHub Pages:** من إعدادات المستودع Settings ← Pages ← اختر الفرع `main` والمجلد `/ (root)`.

بعد الربط يتحدّث الموقع تلقائيًا عند كل `git push`.
